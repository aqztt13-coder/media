# دليل مشروع «دليل أطباء البصرة» (Basra Doctors Directory)

موقع وتطبيق ويب إلكتروني متكامل واحترافي للبحث عن الأطباء والعيادات الاستشارية في **محافظة البصرة**، باللغة العربية مع واجهة RTL كاملة، وخريطة تفاعلية بالاعتماد على **OpenStreetMap و Leaflet**، ومحرك بحث ذكي يتجاهل الفروقات الإملائية والتشكيل، ولوحة تحكم محمية للأدمن لرفع ملفات Excel وتحديث قاعدة البيانات المركزية فورياً.

---

## 🌟 ١) الفكرة العامة والمميزات الرئيسية

- **واجهة بحث عربية RTL حديثة:** مخصصة للجوال والحواسيب بخط Cairo وألوان طبية مريحة (تركوازي، أزرق داكن، أبيض ولمسات زمردية).
- **بحث فوري حي (Live Search):**
  - يعمل أثناء الكتابة بالاسم، الاختصاص، المنطقة أو الملاحظات.
  - يتجاهل الفروقات العربية: الهمزات (أ/إ/آ/ٱ -> ا)، الألف المقصورة والياء (ى/ي)، التاء المربوطة والهاء (ة/ه)، التشكيل، والتطويل.
  - يدعم معالجة الأخطاء الإملائية البسيطة (Fuzzy Matching عبر Levenshtein Distance).
- **فلاتر متعددة:**
  - فلتر بحسب الاختصاصات الطبية (مولد تلقائياً من البيانات).
  - فلتر بحسب مناطق وأقضية محافظة البصرة (العشار، الجبيلة، الجزائر، الطويسة، المعقل، بريهة، الخورة، الزبير، القرنة، أبو الخصيب، الهارثة، شط العرب، دور النفط...).
- **أزرار الإجراءات في بطاقة كل طبيب (كبيرة ومناسبة للهواتف):**
  1. **اتصال هاتفي مباشر:** يفتح طلب الرقم عبر الرابط `tel:`.
  2. **محادثة واتساب:** يفتح محادثة واتساب عبر الرقم الدولي العراقي `https://wa.me/964XXXXXXXXXX`.
  3. **رسالة واتساب مسبقة الصياغة:** يفتح واتساب مع نص جاهز لحجز موعد:
     > "السلام عليكم دكتور [الاسم]، أرغب بحجز موعد، وجدت رقمكم في دليل أطباء البصرة."
  4. **خريطة موقع العيادة (Modal):** خريطة تفاعلية عبر Leaflet + OpenStreetMap (مجانية بدون أي مفاتيح API مدفوعة)، مع زر فتح في **خرائط Google** وزر **الاتجاهات للعيادة**، ونظام تخزين مؤقت (Cache) لعمليات التحديد الجغرافي.
  5. **مشاركة البطاقة:** نسخ معلومات ورابط الطبيب للحافظة بنقرة واحدة.
- **حالة قاعدة البيانات الفارغة:**
  - عند عدم وجود بيانات، تظهر رسالة لطيفة: «لا توجد بيانات حالياً» مع توجيه للوحة الإدارة لرفع الملف.
- **لوحة إدارة محمية للأدمن:**
  - تسجيل دخول مشفر عبر `bcrypt` وجلسات آمنة بـ `JWT`.
  - حماية من المحاولات المتكررة (Rate Limiting) وقفل تلقائي بعد 5 محاولات خاطئة لمدة 15 دقيقة.
  - إحصائيات فورية (عدد الأطباء، عدد الاختصاصات، تاريخ آخر تحديث).
  - سحب وإفلات لملف Excel مع معاينة فورية (عدد الصفوف، أول 10 صفوف، الأخطاء).
  - خياران للاستيراد: "استبدال كافة البيانات" أو "إضافة مع منع التكرار" (بالاسم ورقم الهاتف).
  - تحميل نموذج Excel فارغ بالأعمدة الخمسة الدقيقة.
  - تصدير بيانات الأطباء الحالية إلى ملف Excel.
  - إضافة وتعديل وحذف الأطباء يدوياً مع إمكانية إدخال خطوط العرض والطول.
  - تغيير كلمة مرور الأدمن.

## 📊 ٣) مواصفات ملف Excel المطلوب رفعه

أعمدة الملف **بهذا الترتيب بالضبط**:
1. **اسم الطبيب** (إلزامي): مثل `د. أحمد علي البصري`
2. **الاختصاص** (إلزامي): مثل `جراحة العظام والكسور`
3. **رقم الهاتف** (إلزامي): مثل `07801234567` (يقوم النظام تلقائياً بتحويله للصيغة الدولية `9647801234567` للواتساب وتنسيقه للاتصال).
4. **العنوان** (إلزامي): مثل `البصرة - الجبيلة - مقابل المستشفى العام`
5. **الملاحظات** (اختياري): مثل `عيادة مسائية من ٤ إلى ٨ مساءً`

> يتوفر ملف نموذجي جاهز باسم `sample_doctors_basra.xlsx` يمكن تحميله من لوحة الأدمن أو من جذر المشروع.

## 🚀 ٤) التثبيت والتشغيل المحلي

### المتطلبات
- Node.js (الإصدار 18 أو 20 أو 22)
- مدير الحزم npm

### خطوات التشغيل
1. انتقل لمجلد الخادم وثبّت الحزم:
   ```bash
   cd server
   npm install
   ```

2. أنشئ ملف البيئة `.env` من الملف النموذجي:
   ```bash
   cp .env.example .env
   ```

3. شغّل سكربت إعداد حساب المدير الأولي (Seeding):
   ```bash
   npm run seed
   ```
   *بيانات الدخول الافتراضية للمدير:*
   - **اسم المستخدم:** `admin`
   - **كلمة المرور:** `AdminSecurePassword2026!`

4. شغّل الخادم:
   ```bash
   npm start
   ```

5. افتح المتصفح:
   - **الموقع العام للزوار:** `http://localhost:5000`
   - **لوحة إدارة الأدمن:** `http://localhost:5000/admin`
   - **فحص صحة الـ API:** `http://localhost:5000/api/health`

## 🔐 ٥) كيفية إعداد بيانات وحماية الأدمن

- يتم تخزين كلمة المرور مشفرة بتقنية **bcrypt (Salt rounds = 10)** في جدول `admins`.
- يتم إصدار رمز JWT آمن صالح لمدة 7 أيام.
- جميع مسارات `/api/admin/*` محمية بـ Middleware يتحقق من صلاحية التوكن.
- النظام مزود بحماية **Rate Limiting**: إذا قام أي مستخدم بإدخال 5 محاولات دخول خاطئة، يُقفل تسجيل الدخول مؤقتاً لمدة 15 دقيقة مع إظهار رسالة واضحة للمستخدم.
- يمكن للمدير تغيير كلمة المرور في أي وقت من زر «تغيير كلمة المرور» داخل لوحة التحكم.

## ☁️ ٦) كيفية النشر على الإنترنت (Deployment)

### أ) النشر على Render أو Railway (الأسهل والأسرع)
1. ارفع المشروع إلى مستودع GitHub خاص بك.
2. في لوحة تحكم Render:
   - اختر **New Web Service**.
   - اربط المستودع وحدد مجلد `Root Directory` كـ `server`.
   - أمر البناء (Build Command): `npm install && npm run seed`
   - أمر البدء (Start Command): `node src/server.js`
   - أضف متغيرات البيئة من ملف `.env.example`:
     - `PORT=5000`
     - `JWT_SECRET=your_long_random_secret_key`
     - `ADMIN_USERNAME=admin`
     - `ADMIN_PASSWORD=YourStrongPassword`
3. سيتم تزويدك برابط مباشر يعمل بتقنية HTTPS ومتاح على مدار الساعة.

### ب) النشر على خادم VPS (Ubuntu 22.04 / 24.04 مع Nginx و PM2)
1. انسخ ملفات المشروع إلى الخادم:
   ```bash
   git clone <REPO_URL> /var/www/basra-doctors
   cd /var/www/basra-doctors/server
   npm install --production
   npm run seed
   ```
2. شغّل الخادم بواسطة PM2 لضمان استمرارية التشغيل عند إعادة التشغيل:
   ```bash
   npm install -g pm2
   pm2 start src/server.js --name "basra-doctors"
   pm2 startup
   pm2 save
   ```
3. اضبط خادم Nginx لعكس المنفذ (Reverse Proxy):
   ```nginx
   server {
       listen 80;
       server_name yourdomain.com;

       location / {
           proxy_pass http://127.0.0.1:5000;
           proxy_http_version 1.1;
           proxy_set_header Upgrade $http_upgrade;
           proxy_set_header Connection 'upgrade';
           proxy_set_header Host $host;
           proxy_cache_bypass $http_upgrade;
       }
   }
   ```
4. فعّل شهادة SSL المجانية عبر Certbot:
   ```bash
   sudo certbot --nginx -d yourdomain.com
   ```

## 🩺 ٧) التحقق وتجربة النظام

1. عند فتح الموقع للمرة الأولى، يظهر الدليل فارغاً وتظهر رسالة: **«لا توجد بيانات حالياً»**.
2. افتح الرابط `/admin` وسجل الدخول باستخدام `admin` و `AdminSecurePassword2026!`.
3. اضغط على "تحميل نموذج Excel فارغ" أو استخدم الملف المرفق `sample_doctors_basra.xlsx`.
4. ارفع الملف عبر خاصية السحب والإفلات، وستظهر معاينة فورية بأول 10 صفوف وإجمالي الصفوف.
5. اختر "استبدال" أو "إضافة مع منع التكرار" واضغط "تأكيد رفع وحفظ البيانات".
6. عد إلى الصفحة الرئيسية (`/`)؛ ستجد أن جميع الأطباء ظهروا فوراً دون الحاجة لإعادة تشغيل الخادم، وأزرار الاتصال والواتساب والخريطة تعمل بكفاءة تامة.
